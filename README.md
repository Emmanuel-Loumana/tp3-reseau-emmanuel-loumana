## Lancer un projet

Télécharger le dépôt avec **Code → Download ZIP**, puis décompresser l’archive. Ouvrir le dossier de la partie choisie dans un terminal, VS Code ou PyCharm et suivre son README.

Chaque dossier contient ses propres fichiers `requirements.txt`, `launch.py` et `CONCEPTION.md`. L’installation et le lancement se font depuis ce dossier :

```bash
python -m pip install -r requirements.txt
python launch.py
```

Sous Windows, `py` peut remplacer `python`. Après l’installation des dépendances, `lancer.bat` permet aussi de démarrer le projet.
